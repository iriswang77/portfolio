How I work

My pattern is consistent: define the problem precisely, build something real enough to test, and let evidence decide — including when the evidence says the elegant solution is wrong.

In the AI work that means treating the interface contract as the product: what the system claims, how it shows its sources, and how it behaves when it does not know.
